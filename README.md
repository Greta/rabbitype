# Rabbitype

I originally made Rabbitype to help my daughter learn to touch type. It's a small, playful place to get comfortable with the keyboard, one short practice session at a time.

[Give it a try](https://greta.github.io/rabbitype/) · [Find me on GitHub](https://github.com/Greta)

![Rabbitype with its colorful typing area, practice options, and personal bests](docs/rabbitype-desktop.png)

## Settle in and start typing

Pick a practice mode and choose 30 seconds, one minute, or two minutes. The timer starts when you begin typing, so there's no rush to get ready.

- **Everyday words** gives you a little bit of everything.
- **Home row** helps you get familiar with where your fingers rest.
- **Top row** gives the upper keys some attention.
- **Bottom row** uses short letter patterns to practice those lower keys.

You'll see your speed and accuracy as you go. Mistakes are marked clearly, and you can use Backspace to work through them. You can pause whenever you need a break. Rabbitype also pauses when you switch away.

At the end, you'll get a look at how you did. Your personal bests and recent sessions stay in your browser, ready for next time. There's no account to create.

## A few design choices

Short sessions make it easy to fit in a little practice. Speed and accuracy sit together so getting the letters right gets just as much attention as going faster.

The cyan, magenta, yellow, and black palette keeps things bright and playful. The layout stays simple, with room to focus on the words. Clear keyboard controls and underlined mistakes help make practice easier to follow.

## Take a look around

Rabbitype is built with React, TypeScript, and plain CSS, with Vite to run and build it.

To run it on your own computer, use Node.js 24 and enter:

```sh
npm ci
npm run dev
```

Then open the local link shown in your terminal. You can run `npm run check` to check formatting, run the tests, and make sure the app builds.

Happy typing!
